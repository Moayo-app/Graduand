# Graduand

**적어 둔 규칙이 지금 커밋에서도 지켜지는지 판정합니다.**

[English](README.en.md)

규칙을 문서에 적어 두는 것과 그 규칙이 지켜지는 것은 다른 일입니다. graduand 는 규칙을 코드로
쥐고 저장소가 지금 그 규칙과 맞는지 판정합니다. 답은 **통과 · 위반 · 미판정** 셋뿐입니다. 보지
못한 칸을 통과로 세지 않습니다.

판정은 **여러분의 CI 에서** 돕니다. 호스팅 SaaS 가 아닙니다. 저희 인프라가 여러분 저장소를
읽는 자리는 없습니다.

## 구독

구독 창구는 **<https://graduand.dev>** 하나입니다 — 가격도 결제도 그 화면에서만 섭니다. 이
저장소에 두 번째 창구는 없습니다.

⭕ **그 주소가 섭니다** — 도메인이 붙었습니다(2026-10-28 실측: 200, `/en/` 로 리다이렉트).

⭕ **구독해도 판정은 여러분 쪽에서 돕니다** — 그 경계는 움직이지 않습니다. 가르는 기준은
**선언이 필요한 기능인가**입니다: `refs` 는 선언 없이 수가 나오고, 선언을 분모로 쓰는 축 셋과
편입 · 격자 · 면제는 자격을 묻습니다. 자격을 묻는 자리에서도 칸의 **구성은 그대로 보이고**
수만 나오지 않습니다.

## 무엇을 판정하나요

| 판정기 | 묻는 것 |
|---|---|
| `refs` | 문서가 가리키는 파일 · 경로 · 앵커에 저장소를 클론한 사람이 실제로 도달하는가. 선언이 없어도 수가 나오는 축입니다 |
| `shared-values` | 색 · 간격 같은 공유값이 저장소가 적어 둔 기준값과 같은가 |
| `shared-values-cross` | 그 기준값이 정본 저장소의 값과 아직 같은가. 저장소 사이에서 벌어지는 갈라짐입니다 |
| `ui-paths` | 선언한 UI 경로가 실재하는 디렉터리인가 |

해석되지 않는 값(`var()` 간접 참조 · 같은 스코프의 중복 정의)은 추측하지 않고 **미판정**으로
남깁니다. 미판정은 「위반 0」이 아닙니다. 재지 못했다는 뜻이고 사유가 칸마다 적힙니다.

무엇을 잴지는 저장소 루트의 `graduand.json` 이 선언합니다. 선언하지 않은 칸은 위반이 아니라
미판정입니다. 적용하지 않기로 한 규칙은 **사유와 만기를 달아** 면제로 적습니다.

## 명령어

설치 없이 한 줄로 돕니다. 어느 명령이 있는지는 `--help` 가 말합니다.

```
npx graduand --help
```

| 명령 | 하는 일 |
|---|---|
| `graduand` | **판정합니다.** 하위 명령이 없는 것이 판정입니다 |
| `graduand init` | 빈 `graduand.json` 을 **씁니다** |
| `graduand canon` | 「여기가 정본이다」를 적습니다 — 공유값 축 하나를 선언에 더합니다 |
| `graduand link` | 「정본은 저기이고 값은 이것이다」를 적습니다 — 박제를 정본에서 **읽어** 적습니다 |
| `graduand rules` | 선언이 **무엇을 분모로 세웠는지**를 냅니다. 판정하지 않습니다 |
| `graduand deliver` | 정본과 갈라진 값을 하류 저장소에 **다시 씁니다** |
| `graduand activate` | 구독 키를 자격 핸들로 바꿔, 커밋할 파일 하나를 씁니다 |

⛔ **어느 명령도 커밋하지 않습니다.** 파일을 쓰는 것과 이력에 넣는 것은 다른 행위이고, 둘째는
여러분의 몫입니다. ⛔ **어느 명령도 저희에게 저장소를 보내지 않습니다** — 네트워크를 타는
자리는 `activate` 하나이고, 그것이 묻는 상대는 결제 벤더입니다.

### 판정 — `graduand`

```
npx graduand
```

선언을 읽고 편입된 규칙마다 칸을 내 **통과 · 위반 · 미판정**을 셉니다. 종료 코드는 셋입니다:
`0` 위반 0 · `1` 위반 1건 이상 · `2` **판정 실패**(선언이 깨졌거나, 선언과 실물이 서로 다른
말을 합니다). ⚠️ `2` 는 「위반이 많다」가 아닙니다 — **재지 못했다**는 뜻입니다.

저장소 사이의 갈라짐(「박제 == 정본」)은 **한 잡이 두 체크아웃을 다 볼 때만** 섭니다. `--root`
를 반복해 시야를 넓히십시오 — 첫 자리가 판정 대상이고 나머지가 시야입니다.

```
npx graduand --root . --root ../design-system
```

보고의 꼴은 셋입니다. 기본은 사람이 읽는 글이고, `--json` 은 기계가 읽는 봉투, `--fragment`
는 주소 하나에 담긴 요약입니다. `--open` 은 그 요약을 브라우저의 진단 화면에서 엽니다.

### 선언을 짓는다 — `init` · `canon` · `link`

빈 선언부터 세우려면:

```
npx graduand init
```

**정본 저장소**(규칙의 원본이 사는 곳)에서는 「여기가 정본이다」를 적습니다. `--file` 은
반복됩니다.

```
npx graduand canon --axis design --adapter css-custom-properties --file tokens.css --scope :root
```

**그 정본을 받는 저장소**에서는 정본의 주소를 가리키고 박제 값을 적습니다. ⭐ 박제를 손으로
받지 않습니다 — 정본 체크아웃을 `--root` 로 함께 보여 주시면 거기서 **읽어** 적습니다.

```
npx graduand link --axis design --canon acme/design --canon-file tokens.css --canon-scope :root --root . --root ../design
```

⛔ 정본이 시야에 없으면 빈 박제를 쓰지 않고 거절합니다. 어디서도 읽지 않은 박제는 지어낸
기준이고, 틀린 기준은 없는 기준보다 나쁩니다. ⛔ 선언이 이미 있으면 덮어쓰지 않습니다 —
조립한 전문을 표준출력으로 내보내고, 옮기는 것은 여러분입니다.

### 분모를 묻는다 — `rules`

```
npx graduand rules
```

선언이 **무엇을 분모로 세웠는지**를 냅니다 — 편입한 규칙과 그 규칙이 고른 판정기, 공유값
축마다의 정본 주소, 면제와 그 만기입니다. 판정하지 않으므로 빨강이 없습니다(종료 코드는 `0`
아니면 `2`). `--json` 으로 기계가 읽는 꼴을 받습니다.

### 갈라진 값을 되돌린다 — `deliver`

판정은 갈라짐을 **보여 주고 거기서 멈춥니다.** 그것을 고치는 일은 지금 사람이 하고, 저장소
N 개에 같은 값을 손으로 옮기는 그 행위가 바로 이 제품이 재는 갈라짐의 **생산 공정**입니다.
`deliver` 가 그 공정을 걷어 냅니다.

```
npx graduand deliver --root . --root ../design
```

정본에서 읽은 값으로 하류 저장소의 파일을 **다시 씁니다.**

**기전은 네 줄입니다.**

1. **당기는 쪽이 하류입니다.** 정본은 자기를 받는 저장소의 목록을 갖고 있지 않습니다 —
   포인터(`canon`)가 **하류의 선언**에 적혀 있어 방향이 하류→상류입니다. ⛔ 그래서 상류가
   하류로 **밀 수 없습니다.** 하류의 CI 가 상류를 시야에 넣고(`--root` 반복) 돌립니다.
2. **분모는 받는 쪽의 선언입니다.** 나르는 것은 그 저장소가 **박제한 토큰**뿐이고, 보내는
   쪽이 그 분모를 넓히지 않습니다. 분모를 넓히는 것은 받는 쪽의 **선언 행위**입니다.
3. **건드리지 않는 자리가 셋입니다.** ⛔ 사유를 달아 기준을 옮긴 값(`diverged`) — 되돌리면
   그 선언을 말없이 취소하는 일입니다. ⛔ 하류가 박제하지 않은 정본 토큰 — 그 자리는 교차
   축이 이미 **위반**으로 세고, 조용히 메우면 그 위반이 영원히 발각되지 않습니다.
   ⛔ 정본이 모르는 박제 — 저장소 고유값이라 정당합니다.
4. **쓰기만 합니다.** ⛔ 커밋하지도 스테이징하지도 않습니다 — 파일을 쓰는 것과 이력에 넣는
   것은 다른 행위이고, 둘째는 여러분의 몫입니다. ⛔ 빨강도 내지 않습니다: 더하지 않은 자리도
   갈라짐도 **판정**이 셉니다. 같은 사실을 두 손이 세면 그 둘은 갈라집니다.

⛔ **저희 인프라가 도는 배달이 아닙니다.** 여러분 조직 안에서 여러분의 CI 가 돌립니다 —
저희가 여러분 저장소를 읽거나 쓰는 자리는 여기에도 없습니다.

⬜ **반대 방향은 아직입니다.** 하류가 옳고 정본이 낡은 경우에 **기준 자체를 옮기는**
일(승격)은 서 있지 않습니다. 배달은 고를 것이 없지만(정본이 기준입니다) 승격은 「어느 쪽이
옳은가」를 정하는 **판단**이라, 그 판단을 저희가 대신하지 않습니다. 설 때의 모양은 정해져
있습니다 — 관측된 드리프트 중에서 **사람이 고르고**, 기계는 후보까지만 말합니다.

### 자격 — `activate`

```
npx graduand activate
```

구독 키를 자격 핸들로 바꿔, **커밋할 파일 하나**를 씁니다. 키는 환경에서 오고(비밀) 핸들은
파일로 갑니다(커밋됩니다). 키가 없으면 `2` 로 거절합니다 — 그 `2` 는 결함이 아니라 「키를
넣어라」는 참된 거절입니다.

## 이 저장소가 담는 것

**판정기 · 어댑터 · 진단 페이지 소스 · 사이트 배선 · 저장소 운영 · 정책 문서 · 증서 전문.**
이 목록이 범위의 정의입니다. 어느 경로가 어느 묶음인지는 산문이 아니라
[`config/public-scope.yml`](config/public-scope.yml) 의 **행**이 갖습니다.

## 라이선스

이 저장소는 **한 벌의 허가로 덮이지 않습니다** — 성질이 다른 넷이 한 트리에 삽니다.

| 묶음 | 허가 |
|---|---|
| 판정기 · 진단 페이지 (파는 제품) | **BSL 1.1** — [`LICENSE`](LICENSE) · 무료 범위는 Additional Use Grant 에 **기능으로** ([경계](docs/licensing/feature-boundary.md)) · Change License = Apache-2.0 |
| 가드 · CI · 선언 · 입구 산문 (저장소 운영) | **Apache-2.0** — [`LICENSE-APACHE-2.0`](LICENSE-APACHE-2.0) |
| 약관 · 환불 · 개인정보 ([docs/policies/](docs/policies/)) | **all rights reserved** — 읽히기 위해 공개하고, 재사용 허가는 두지 않습니다 |
| 두 증서의 전문 자체 | 각자의 저작권자(MariaDB · ASF) 조건대로 |

⚠️ **어느 경로에 무엇이 붙는지의 정본은 산문이 아니라 선언입니다** —
[`config/public-scope.yml`](config/public-scope.yml) 의 `license` 축이 **행마다** 적고, 그
값이 빠진 행은 가드가 막습니다(침묵의 기본값은 all rights reserved 이고, 그 뜻은 「아직 안
정했다」가 아니라 「베껴 쓸 수 없다」입니다). 묶음마다의 **사유**는
[docs/licensing/repository-licensing.md](docs/licensing/repository-licensing.md) 가 갖습니다.
