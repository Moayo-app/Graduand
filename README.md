# Graduand

> ⚠️ 이름 `graduand` 는 잠정이다.

규칙을 코드로 쥐고, 에이전트가 낸 일을 그 규칙으로 판정한다. 판정은 **고객의 CI 에서** 돈다 —
호스팅 SaaS 가 아니고, 우리 인프라는 고객 저장소를 읽지 않는다.

이 저장소가 담는 것: **판정기 · 어댑터 · 계측기 · 진단 페이지 소스.** 이 목록이 범위의 정의다.

할 일의 전부이고, 닫힌 이슈가 결정의 색인이다. 세션 부트스트랩은 [CLAUDE.md](CLAUDE.md).
