graduand

저장소 구성 진단

문서의 참조와 선언된 UI 경로가 지금 커밋과 맞는지, 이 브라우저가 직접 판정한다. 요청은 api.github.com 으로만 나가고, 판정 결과는 어떤 서버로도 전송되지 않는다.

구독이 활성화됐다.

공개 저장소

주소를 넣으면 이 브라우저가 GitHub API 에서 직접 읽어 그 자리에서 판정한다 — 중간에 서는 서버가 없다.

비공개 저장소

코드도 토큰도 보내지 않는다 — 판정은 저장소가 있는 기계에서 돌고, 결과 요약만 주소(fragment)로 이 페이지에 열린다.

npx graduand --open

이 페이지에 PAT(토큰) 입력 칸은 없다 — 빠뜨린 게 아니라 설계다. 토큰 붙여넣기를 가르치는 제품이 되지 않는다.

선언을 시작한다

미판정으로 남은 축은 선언이 없기 때문이다 — 분모를 선언하지 않으면 「위반 0」이 아니라 미판정이다. 아래가 그 빈 선언이고, 저장소 루트에 graduand.json 으로 두면 다음 판정부터 분모가 선다. 체크아웃이 없어도 된다 — 복사해 붙이는 것이 전부다.


      
      

      
편입 기록이 비어 있는 것이 정당하다 — 「아직 아무 규칙도 편입하지 않았다」는
        참인 선언이고, 그 칸은 전부 미판정으로 남는다. 빈 상태를 결함처럼 다루지 않는다.

      
⭐ 규칙을 편입할 때 적는 것은 규범 정본을 가리키는 이름이다 —
        같은 규범을 저장소마다 베껴 두면, 그 사본들이 갈라지는 것이 바로 이 페이지가 재는 것이다.

      
체크아웃이 있으면 같은 내용을 같은 자리에 쓰는 명령이 있다 — 기존 선언을
        덮어쓰지 않고, 커밋하지도 않는다.

      
npx graduand init
