# Design Tokens: Shared Values

디자인 토큰의 공유값 등록부 — 무엇이 서비스 간 공유값이고, 무엇이 서비스 소관이며,
공유값을 어떤 기전으로 소비하는지.

## 읽기 경로

디자인 토큰(색·폰트 등)을 **만들거나 소비하는 구현 티켓**에 착수하기 전에 읽는다.
토큰을 건드리지 않는 작업은 이 파일을 읽지 않는다.

## 공유값 등록부 — 먹 램프 6색

한지 바탕 + 먹 램프 — 위계는 색이 아니라 먹의 농담이 진다.

| 이름 | 값 | 쓰임 |
|---|---|---|
| `base` | `#F7F6F3` | 한지 — 바탕 |
| `inkBurnt` | `#1A1D2E` | 焦墨 — 본문·아이콘 |
| `inkDense` | `#2D3142` | 濃墨 — 부본문 |
| `inkHeavy` | `#6B6E80` | 重墨 — 보조·물러난 요소 |
| `inkLight` | `#C8CAD2` | 淡墨 — 괘선·비활성 |
| `inkClear` | `#EFEFF2` | 淸墨 — 구분선 |

## 공유값 등록부 — 치수

색이 아닌 공유값의 자리다. 값은 **단위 없는 수**이고, 단위(`px` · `dp` · React Native
무단위)는 소비하는 쪽이 자기 형식에 맞게 붙인다.

| 이름 | 값 | 쓰임 |
|---|---|---|
| `tapMin` | `44` | 탭 타깃 하한 — 누를 수 있는 것의 시각 높이·너비가 이 아래로 내려가지 않는다 |

⭐ **이 표는 사본이 아니라 정본이다.** 서비스의 `packages/ui/src/tokens/shared-tokens.ts`
는 이 표에서 **기계가 낳고**, 서비스 코드는 그 생성물을 임포트해 자기 이름을 얹는다.
위 먹 램프 6색의 복사 기전과는 **다른 층이며**, 둘의 차이는 아래 「소비 규율」이 적는다.

⚠️ **`tapMin` 은 표본 1 이다.** 먹 램프 6색은 이 기전으로 넘어가지 않았다 — 확대는 별도
결정이다.

⚠️ **하한을 위계에서 유도하지 않는다.** 위계는 시각 리듬이고 하한은 **접근성 계약**이라,
하나를 다른 하나에서 유도하면 위계를 조정할 때 접근성이 조용히 따라 움직인다. 컨트롤 높이가
하한 아래인 자리는 실재할 수 있고, 그 사실은 산문이 아니라 **spec 단언**이 든다.

## 경계 — 등록부 밖은 서비스 소관이다

담채(pigment) 팔레트 · 변형 선택 · 적용 정책은 **서비스가 정한다.** 같은 이름의 담채가
서비스마다 **의도적으로 다른 값**일 수 있고, 그 갈림을 서비스의 spec 이 단언으로 지킨다.

규칙 형태(축)도 이 등록부가 선언하지 않는다 — 축은 두 서비스에서 독립 발생했을 때만
승격된다.

## 소비 규율

⭐⭐ **기전이 표마다 다르다 — 표를 먼저 보고 규율을 고른다.**

| 표 | 기전 | 정본 |
|---|---|---|
| 먹 램프 6색 | **복사** + 출처 주석 + 자체 값 고정 가드 | 이 표 (사본은 서비스 코드) |
| 치수 | **생성 배포** — 등록부에서 기계가 낳은 `shared-tokens.ts` 를 임포트한다 | 이 표 |

⚠️ 두 표에 같은 규율을 적용하면 **한쪽이 반드시 틀린다.**

**먹 램프 6색 — 복사**

- 기전은 **복사 + 출처 주석 + 자체 값 고정 가드**다 — 상류에서의 임포트가 아니다.
- 복사한 자리에는 **출처를 주석으로 남긴다** — 어느 표의 어느 판에서 떠왔는지.
- ⭐ **토큰 값 박제(value-pin) — 승격된 축이다**: **확정한 토큰 값은 — 공유값이든 서비스값
  이든 — 코드 선언만으로 두지 않고 spec 테스트가 hex 리터럴로 박제한다.** 값 변경은 spec 을
  함께 바꾸는 PR 이어야 한다. 축은 형태의 선언이지 강제가 아니다 — 가드 없는 토큰이 위반은
  아니며, 어느 토큰에 붙일지는 서비스가 정한다.

**치수 — 생성 배포**

- 값을 손으로 옮겨 적지 않는다. 등록부가 낳은 `packages/ui/src/tokens/shared-tokens.ts` 를
  **임포트**해서 쓴다 — 저장소 안은 임포트, 저장소 간은 생성이다.
- 그 파일은 **생성물이라 손으로 고치지 않는다.** 고치면 `drift` 가 잡는다.
- 서비스가 얹는 이름·별칭·적용 정책은 서비스 소관이다 — 생성물은 **값 층**만 낳는다.
  값을 바꾸려면 이 표를 고치는 PR 을 낸다.
- 착지 박자는 문서 공유 블록과 같다 — 등록부 PR 이 머지되면 **곧바로** 서비스 재배포 PR 이고,
  지연은 교차검증 빨강이다.

이 등록부를 서비스마다 다르게 쓰려면 **이 파일이 아니라 상류의 템플릿을 고친다** — 여기서
고친 차이는 재생성 때 사라지고, 사라지기 전까지는 드리프트로 실패한다. 의도적으로 갈라져야
한다면 서비스 블록 마커로 선언한다.
